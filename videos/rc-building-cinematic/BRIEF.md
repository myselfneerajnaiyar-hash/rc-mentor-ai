## Intent

Animate one premium contemporary house being physically built in one continuous
3D scene. The construction and continuous camera journey carry the metaphor:
site → foundation/rebar → rising pillars → beams that slide and lock → walls and
rooms → assembling roof → finished home. No still-image sequence, cartoon,
fake RC passage, or sales CTA. User will add narration later.

## Visual system

Use physically based concrete, limestone, teak, bronze, and glass materials,
golden-hour lighting, soft shadows, restrained dust, and subtle white typography.
Preserve one house, one camera move, and the existing quiet instrumental bed.

## Copy

Opening: “RC / IS A BUILDING.”
Foundation: “FOUNDATION / TOPIC.”
Pillars: “PILLARS / PARAGRAPHS.”
Beam locks: “BUT / HOWEVER / THEREFORE / INSTEAD,” followed by “LOGIC.”
Rooms: “EVIDENCE / EXAMPLES.”
Roof: “AUTHOR’S MAIN POINT / ROOF.”
End: “DON’T JUST READ THE RC. / SEE ITS STRUCTURE.”

No voiceover. No invented passage. No sales copy.
