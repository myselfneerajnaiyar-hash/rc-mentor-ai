# Auctor VARC Bootcamp promo — Version 2

## Reference review

The Yash reference is a 34.5-second vertical SaaS explainer. Across one-second frame samples, it uses a continuous navy field with blue-violet glow, concise centered copy, UI cards that enter at different scales, and regular shifts from headline to product evidence. Its strongest technique is keeping the main message and the interface close together while moving the crop and focal point. Version 1 uses a restrained navy/orange style, but its first scene holds in an almost empty frame, and several scenes leave the captured interface too small to read. Version 2 keeps Auctor's colors and uses its own copy, storyboard, and transitions.
